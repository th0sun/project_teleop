# Dobot Reference Manuals

This folder stores Dobot manuals that are useful to the main project but should
not live inside the `Dobot_TCP_IP_Python_V4` submodule working tree.

Files currently kept here:

- `TCP_IP Remote Control Interface Guide (4axis)_20240419_en.pdf`
- `Dobot MG400 Hardware User Guide_V2.3_20241209_en.pdf`
- `MG400_Hardware_User_Guide_(DT-MG400-4R075-01).pdf`

Reason for this location:

- they are project reference materials, not part of the submodule source tree;
- keeping them here avoids dirty submodule state from local PDFs;
- docs and future contributors have one stable place to find manuals.
