# MG400 Demo QR Landing Page

Stable poster URL target:

```text
https://th0sun.github.io/project_teleop/mg400-demo/
```

The poster QR code should point to that stable page URL, not directly to YouTube.

To change the current demo video later:

1. Edit `video_url.txt`.
2. Put the latest YouTube URL as the only line.
3. Commit and push.

The QR code on the printed poster does not need to change.
